# IEEE YP Pune Section Website

A full-stack web application for the **IEEE Young Professionals Pune Section**, providing a modern public website and CMS for managing events, blogs, campaigns, resources, team members, and announcements.

## 🚀 Features

### Public Website

* Responsive modern UI
* Events & campaigns
* Blogs & resources
* YP Talks
* About & Contact
* Join IEEE
* Newsletter subscription
* Announcements

### Admin CMS

* JWT authentication
* Dashboard
* Event, blog & campaign management
* Team & media management
* Registrations & announcements

## 🛠 Tech Stack

**Frontend:** React, Vite, Tailwind CSS, React Router, Axios, Framer Motion
**Backend:** Node.js, Express.js, PostgreSQL, JWT, bcrypt, Cloudinary, Resend
**Database:** PostgreSQL (Supabase)
**Deployment:** Vercel, Railway, GitHub Actions

## 🎯 Goal

To provide a scalable and engaging digital platform for IEEE Young Professionals Pune Section while enabling easy content management through a CMS.
